# XenoPortal 最小真机验证与诊断设计

这是待实现、待执行的验收清单。所有结果当前为 NOT_RUN。

## 诊断数据

每条记录包含 wall clock、elapsedRealtime、sessionId、stage、结果码、耗时和简短详情。200 行环形日志与 S0～S7 最近状态分开保存，避免文字树刷掉关键阶段。阶段使用 NOT_RUN / RUNNING / OK / FAILED / BLOCKED / UNKNOWN；上次会话成功不能显示为本次成功。

| 阶段 | 至少记录 | 成功定义与限制 |
|---|---|---|
| S0 | onServiceConnected 时间、heartbeat、已启用/已绑定、进程启动、onUnbind/onDestroy | 服务实际连接；仅系统开关开启不算连接。不能仅凭未连接断言被受限制设置拦截，标为原因待确认 |
| S1 | 包名、事件名/数值、windowId、事件时间、接收时间 | 收到任意外部事件；配置不可只订阅抖音以致 S1 无法诊断 |
| S2 | foreground/window 包、白名单版本、匹配结果 | 事件包和内容窗口确认；系统窗口代发与应用弹窗要分清 |
| S3 | 触发来源、指针数、DOWN/UP/MOVE/CANCEL、阈值、坐标、长按菜单规则版本及证据 | 不能将“含保存文案”或“只有一次 DOWN”标成长按确认 |
| S4 | 节点 bounds、截图请求/返回时间、实际像素/字节、mime、来源、媒体候选关联 | 可解码且能在诊断预览内容；拿到未压暗图需人工对照验证，不由存在文件推断 |
| S5 | 协议值、island feature 原始值/异常、canShowFocus 三态、通知/渠道、notify/cancel 调用 | 只标发送已提交；官方岛实际渲染为单独用户确认状态 |
| S6 | 点击 targetId/sessionId、是否过期、重复保护、PendingIntent 类型 | 本应用确实收到本次回调 |
| S7 | ACTION_SEND 的 MIME、目标包、resolve 结果、启动异常 | 只证明启动请求，无通用“对方已发送给好友”回执；人工接收结果单独登记 |

窗口树调试默认关闭。开启后仅白名单窗口，建议每秒最多一次、每次总计最多 1000 节点、限制深度和字符串长度，输出 text/description/id/class/clickable/bounds/windowId/package；达到上限明确记录截断。树日志独立限额，保留 S0～S7 主日志。复制/分享导出由用户点击发起；导出前提示包含窗口文字。应用自身不上传日志和媒体，不加入 INTERNET 权限。

异常处理不能把 Coroutine CancellationException 吞成普通失败；业务/平台调用分段捕获并记录 cause 与固定错误码，不只一个顶层 try/catch。服务进程被直接杀死可能不执行 onDestroy，下次打开通过连接状态与心跳年龄提示“未连接/可能已停止”，不能伪造确定被杀原因。

## 验证记录模板

记录设备型号、完整 HyperOS build、Android/API、SystemUI/焦点插件版本（能查询时）、抖音版本、XenoPortal 版本/签名摘要、权限状态、测试时间、预期、实际、sessionId、日志导出文件。重复至少覆盖不同图片与普通分享反例，不以一次成功取代稳定性验证。

## G0：服务与诊断

1. 冷安装，拒绝通知/媒体权限，打开诊断，确认逐项 BLOCKED 及修复入口。
2. 先不启用无障碍，再启用，验证 S0 从未连接变为连接；若出现系统受限制设置提示，用引导说明处理并记录人工确认。
3. 切换抖音、小红书、微博、微信及非白名单应用，检查 S1/S2，白名单可编辑。
4. 强制停止/关闭无障碍/杀进程、重新打开应用，状态不得保留“在线”。
5. 打开文字树采样，查看所有交互窗口；节点 0、root null、SecurityException、截断均必须可见。可一键清除和导出最近日志。

## G1：触发和取图，必须先通过

1. 抖音评论图片：先正常查看，分别长按、点击普通分享、打开识别图片、点击取消；每个路径导出文字树。用快照差异建立排他规则，不能用想象中文案代替数据。
2. 禁止自动点击的诊断模式下检查 S3 命中与所有普通分享反例。若无法区分，两条路径都不得自动保存；标记菜单方案不满足自动化验收。
3. T1 实验单独验证：记录 20 次点击、滑动、快速滑动、长按、多指、取消和旋转。对照关闭前后的滚动与菜单出现时间。确认 delegation 后事件停止；任何 UP 缺失不得触发定时长按。
4. 截图先用应用内标尺图验证旋转、状态栏/挖孔、缩放与 bounds 变换；之后抖音图片长按时核对截图未压暗。记录 request/return/menu 时序。受保护窗口明确失败。
5. 原图模式先核对完整 READ_MEDIA_IMAGES/VIDEO；Android 14+ 仅选定照片时标记不足，不给“已授权完整读取”。在保存前建立 MediaStore 基线，点击一次后查询增量，预览唯一关联项。
6. 并发让另一应用保存图片；本次候选不唯一时不得分享错误内容。视频模拟慢写、暂停写和大文件，连续两次大小相等不单独视为完成。
7. 对图文、普通视频、动态照片分别记录能力；截图视频写明“当前帧”，JPEG 运动内容不自行拆解或声称被保留。

## G2：显示层

1. 使用合成图片，不依赖 G1。查询协议与权限并展示原始结果。查询在后台线程执行，异常不等于明确拒绝。
2. 官方路径：无授权、关闭总通知、屏蔽渠道、焦点开关前后、平台调测设备等分别测试。不要求用户先 Root。
3. 发送模板 12/15，人工确认大小岛/展开卡片与按钮；记录 notify 成功但无岛的情况。`filterWhenNoPermission` false/true 分开实验，清理对照普通通知。
4. 8 秒超时、点击取消、再次发送同 id、用户划走、锁屏/横屏/分屏、进程终止后不得残留。通知 timeout 和客户端 cancel 双保险需要实际观察。
5. 无权限时覆盖窗口显示；服务断开时移除窗口。无需申请 SYSTEM_ALERT_WINDOW，不引入前台服务启动显示。松手后新手势点目标或在本覆盖窗口内部拖动才计有效。
6. 若 canShowFocus=true 而实际渲染失败，设置页显示“官方通知已提交，显示未确认”，允许强制自绘；不得静默声称已上岛。

## G3：分享与生命周期

目标候选包名仅为输入配置，设备 PackageManager 查询后才算已安装验证：

| 固定顺序 | 目标 | 待查询包名 | 接收契约 |
|---|---|---|---|
| 1 | 保存到相册 | 本应用 MediaStore | 写入成功后检查相册可见，原图模式已有副本时避免再次保存重复 |
| 2 | 微信 | com.tencent.mm | image/* 与 video/* 分开 resolve 与实发；通常选聊天，不能直达指定好友 |
| 3 | QQ | com.tencent.mobileqq | 同上 |
| 4 | 小米互传 | com.miui.mishare.connectivity | 未确认公开契约；无接收 Activity 时显示系统分享入口，不能把任意 launch Activity 当作已分享 |
| 5 | ChatGPT | com.openai.chatgpt | 图片/视频分别测试，不臆造 component |
| 6 | Claude | com.anthropic.claude | 同上 |
| 7 | 豆包 | com.larus.nova | 同上 |
| 8 | DeepSeek | com.deepseek.chat | 同上 |

Manifest `<queries>` 声明候选包及必要 SEND/MIME 查询；包已安装与支持当前 MIME 是不同状态。未安装隐藏并顺延，已安装但不支持当前 MIME 的降级在 UI 说明。选择器降级必须显式标“选择分享应用”，仅拉起应用必须标“未携带文件”。

FileProvider 仅暴露会话专属 cache 子目录，URI/ClipData 读授权；并检查撤权、超大视频、低空间、对方拒收、用户取消等。Activity 启动成功不等于发送成功。

缓存需求存在时序冲突：ACTION_SEND 启动后对方可能延迟打开 URI，立即删除会导致读失败。设计为分享启动即收起岛，文件持有有限租期，用户返回/明确完成后清理，另设过期清扫及“立即清除缓存”。8 秒未操作的未分享会话可直接删除。跨应用发送没有普遍完成回执，不能同时承诺“启动即删且接收一定成功”。租期策略在编码前写进设置说明。

原图模式的相册副本属于宿主写入内容，默认保留；仅本次已关联副本且用户开启“分享后询问删除”才使用 createDeleteRequest 请求系统确认。用户取消删除是正常结果，不静默重试。

每个会话 single-flight：一次手势一个 session；保存等待期间不重复点击；新长按按明确策略替换或提示忙；旧回调/定时器不能取消新会话；重复按钮回调幂等。服务停止、取消、超时、失败、重新启动均核对 notification/window/cache/URI 授权。
