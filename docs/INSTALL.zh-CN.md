# 0.0.2-beta.1 安装与试用

包名 com.xeno.portal，versionCode206，与此前beta/诊断版同签名，覆盖安装。APK无法下载时使用发布页的APK ZIP解压。校验值见SHA256SUMS.txt。

## Root / LSPosed 路线

本APK同时是独立应用和legacy LSPosed模块。需要用户设备已经具备适配该系统的Root与LSPosed；本应用不会获取Root、解锁Bootloader或替你安装框架。

1. 安装后，在LSPosed中启用XenoPortal，作用域仅选抖音 com.ss.android.ugc.aweme。不要勾选系统框架、SystemUI或米服务框架。本版未实现系统进程Hook。
2. 强制停止并重新打开抖音。升级APK后也要这样做，避免宿主继续运行旧模块。
3. 打开XenoPortal，设置中启用总开关和“Root 长按截图”，授权无障碍、普通通知和系统实时通知。侧载受限时在应用信息中检查“允许受限制的设置”。
4. 切回抖音，再进入评论列表。长按一张完全可见的图片/图片表情，默认350ms，可调250–500ms。修改阈值后重新进入抖音页面刷新配置。
5. 日志中的ROOT_BRIDGE连接不等于长按成功。S3检查触点，S4检查命中区域/阻断原因，S5检查官方通知。菜单出现、未命中、坐标不符或太迟时停止，不自动保存抖音内容。
6. 出现系统岛后点击“保存到相册”，直接写Pictures/XenoPortal，不进入XenoPortal分享页面；微信/QQ还需选择聊天。

首次只试评论图片和表情静态帧，不包含原视频、GIF动画。Activity独立弹窗、分屏、放大与其他屏幕尚不支持。即使350ms触发，查询节点和截图仍需时间，不能保证未压暗；需要检查预览。Android16官方岛曾在用户手机显示，但本次Root全链路待实测。

没有连接：确认作用域、同一用户配置文件、重启抖音，检查LSPosed日志。桥接失败会在模块日志显示；应用收到连接后诊断页可见。应用/宿主被系统限制时可能需要检查自启动、省电与后台权限。不能用Root开关状态推断框架已运行。

## 免 Root 手动路线

关闭Root触发，首页“开始选取评论图片（5秒后）”，切到抖音已关闭菜单的评论列表并停止滚动；从临时预览中选图后调用官方岛。临时面板只是选图工具，20秒未操作结束。也可从系统照片选择器导入单张图片，无需完整相册读取；导入JPEG静态图、最长边2048像素。

本版没有自绘岛降级。系统拒绝官方通知时看S5原因，不会悄悄改画悬浮岛。可先用系统照片选择+5秒后显示系统岛，返回桌面验证显示入口，再试Root触发。

## 反馈

诊断页复制/导出S0～S7和最近日志。窗口文字树默认关闭，Root触发不要求开启文字树；导出可能包含之前采集的私人文字，先检查。截图只存私有缓存，主动保存才写相册；分享读取租期最长10分钟，进程退出后下次启动清扫。关闭总开关或Root开关立即停止新取图，模块配置缓存最长30秒，但接收端始终检查当前开关。
