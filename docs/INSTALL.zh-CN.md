# 0.0.1-beta.1 安装与试用

从仓库beta发布页下载APK；手机若拦截APK下载，可下载APK ZIP后解压安装。核对SHA256SUMS。包名com.xeno.portal，版本号205，与此前诊断版同签名，覆盖安装即可。

## 授权

1. 首页打开总开关。
2. 设置→通知权限，允许普通通知。打开系统实时通知权限，允许系统提供的相关开关；没有独立入口时会退回应用通知设置，原因写日志。
3. 需要评论取图时，打开无障碍并连接XenoPortal。侧载受限时，在应用信息菜单检查“允许受限制的设置”；具体入口由ROM决定。
4. 自启动、后台弹出、省电限制按需在应用信息中检查。应用无法可靠判断系统具体拦截原因。

不要求Root、Shizuku、悬浮窗权限或完整相册读取。照片选择使用系统选择器授予的单张读取权限。

## 首次试用

先用首页“从系统照片选择图片”选一张，等待预览，点击“显示官方系统岛（5秒后）”，返回桌面。展开系统岛点保存到相册，应直接写入Pictures/XenoPortal并提示，不进入XenoPortal分享页面。首页也可直接保存或打开全部目标。

然后试评论取图：先将抖音评论列表准备好，返回XenoPortal首页点击“开始选取评论图片（5秒后）”，切回抖音，关闭长按/分享菜单并停止滚动。预览出现后点选一张，官方通知随后发出。临时预览不是系统岛；未选择时20秒结束。表情包只能截当前帧。

这条评论取图依赖当前抖音节点结构，仍需真机验证；读不到、窗口变化或坐标不可靠时会提示阻断，不会随意裁图。自动长按触发尚未启用。

## 问题反馈

诊断页显示S0～S7。S4看取图，S5看通知，S6看按钮回调，S7看保存/分享。复制日志过长会标明摘要，完整内容使用分享导出。文字树默认关闭；只有排查菜单时才开启，导出可能含评论等私人文字，请先检查。

微信/QQ通常需要选择聊天。AI与互传的接收能力逐项试用，不保证视频、GIF或原文件支持。缓存最长10分钟，立即清除可能中断接收方读取。
