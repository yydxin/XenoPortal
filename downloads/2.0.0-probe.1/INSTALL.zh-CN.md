# XenoPortal 诊断版

本轮实现诊断工具与独立显示/分享探针。**不是已通过抖音长按自动分享验收的正式版。** 包名 `com.xeno.portal`，可与小米官方传送门共存。Android 13+，主目标 HyperOS 3 / Android 16。

## 当前能测试什么

- 设置 / 验证工具 / 诊断三页，Compose 深浅色。
- S0～S7 独立状态、最近200行日志、复制和主动分享导出。
- 无障碍实际连接、任意外部事件、白名单过滤、所有可读取窗口采样。检查 text 与 contentDescription；记录 id、class、clickable、bounds。
- 默认关闭窗口文字树，启用后1.5秒限频、最多1000节点，日志每次最多100条节点，受限完整快照另保留供查看/导出。
- 生成合成图，或用户主动点击后5秒截图并预览。截图为全屏诊断截图，不自动裁剪、不声称原图。
- 官方焦点协议/权限查询、通知渠道检查、官方模板探针；不可用时尝试无障碍覆盖窗口，可强制自绘，8秒取消。
- 本机查询已安装分享目标、固定排序隐藏未安装项；相册保存、包限定 ACTION_SEND 与系统面板降级。

## 安装与第一次验证（无需 adb）

1. 安装本次签名 probe APK。打开应用，打开总开关。
2. 点击“打开无障碍设置”，启用 XenoPortal。若系统阻止侧载应用启用，先在应用信息右上角菜单检查“允许受限制的设置”。回到诊断页确认 **S0已连接**，不能只看系统开关。
3. 在“验证工具”生成合成图，授权通知。先按检测结果显示；官方无权限时需无障碍已连接来显示自绘窗口。可在设置中强制自绘。验证相册、微信/QQ目标（设备上安装才显示）。
4. 在“诊断”明确同意开启文字树。进入抖音，分别长按评论区图片、点击普通分享按钮。回到诊断页查看 S1/S2、菜单候选和窗口快照。
5. 如需观察截图：点击“5秒后截取全屏诊断图”，5秒内切到目标界面，之后回来看预览。这不能代替自动长按时序验收。
6. 复制日志，或点击“分享导出”并阅读导出内容提示后，选择自己信任的保存位置。应用不自动发送日志给任何人。

建议检查 HyperOS 的自启动、后台弹出界面与省电设置；不同 ROM 入口可能不同。无障碍未连接时显示具体阻断状态。总开关关闭会取消等待中的截图和显示请求。

## 必须知道的边界

- 本版没有启用自动长按、TouchInteractionController、Shizuku、Root、手势回放或节点自动点击。S3只记录菜单候选，坐标未知；不会自动点“保存到相册”。预留阈值配置不表示触发器已运行。
- 原图模式、MediaStore 外部文件关联、视频/动态照片提取、拖拽文件分享尚未实现。没有 OCR 或文字分享。
- 官方通知未配置开发者平台 App Id / 签名准入。notify 成功只表示提交，不能证明显示了超级岛；实际显示需人工检查。模板与各 ROM 兼容性需要真机验证。
- 目标应用图片分享契约需要设备验证。微信/QQ通常只进入选择聊天，不能直达指定好友。互传未确认公开接收契约；无匹配接收入口时进入系统分享面板，并显示降级说明。启动应用/选择器不等于发送完成。
- 窗口树可能因宿主自绘、厂商限制或安全窗口而不可读；不能假定抖音菜单总能获取。
- 媒体仅保存在本机 cache。未分享的显示会话8秒超时清理；诊断预览和已交接会话使用10分钟租期。进程存活时清理，进程终止后下次打开清扫，不能承诺进程死亡后精确定时删除。立即清除缓存可能影响接收端尚未完成的读取。
- 本版媒体读取权限是后续实验可选项，当前截图/保存合成图无需授权。拒绝权限不影响其他诊断；不会把 Android 14 的“仅所选照片”当作完整读取。

## 构建

使用完整 JDK 17/21 与 Android SDK 36，在 `local.properties` 配置自己的 sdk.dir（此文件不提交）：

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

输出 `app/build/outputs/apk/debug/app-debug.apk`。release 独立签名与密钥备份见 [SIGNING.md](docs/SIGNING.md)。探针测试证书不会自动获得小米平台权限；自己的长期密钥不要上传到仓库。
