XenoPortal 2.0.0-probe.1 诊断版安装说明

适用：Android 13 或更高版本，主目标为 HyperOS 3。
安装包：XenoPortal-2.0.0-probe.1-redelivery.apk
包名：com.xeno.portal；版本号：200。

1. 下载 APK；如果下载的是 APK-bundle.zip，先解压取得 XenoPortal.apk。
2. 在手机上打开 APK，按系统提示允许用于安装的浏览器/文件管理器安装应用。
3. 打开 XenoPortal，开启总开关，进入无障碍设置启用 XenoPortal。
4. 若侧载应用被系统限制，检查“应用信息 → 右上角菜单 → 允许受限制的设置”，再回无障碍设置。不同系统入口可能不同。
5. 返回诊断页确认 S0 已连接，不能仅凭系统开关判断服务运行。
6. 在“验证工具”生成合成图，授权通知，测试显示与分享。官方岛无权限时尝试自绘覆盖窗口，也可在设置中强制自绘。
7. 如需采集抖音菜单：在诊断页同意开启窗口文字树，分别操作“长按评论图片”和“普通分享按钮”，每种场景分别导出日志。日志可能含窗口私人文字，请自行检查后再分享。

重要边界：
- 这是诊断版，不是已通过真机验收的正式版本。
- 自动长按提取、自动点击保存、原图关联、视频/动态照片提取尚未启用。
- 本版可生成合成图、用户主动延迟截图、查看 S0～S7 状态、采样窗口、测试显示和图片分享。
- APK 使用独立诊断证书，未登记小米平台权限；notify 成功不代表真正上岛。
- 微信/QQ一般进入选择聊天页，不能直达指定好友。互传与 AI 应用接收能力需真机验证。
- 应用不申请网络权限，不上传媒体或日志。导出仅由你主动点击。
- 未分享显示会话8秒超时收起；诊断预览和已交接文件使用10分钟租期，进程存活时清理，进程被杀后下次打开清扫。
- 如果已安装另一签名的同包名版本，可能无法覆盖安装；卸载会清空应用数据，请先保存需要的日志。

源码包：XenoPortal-2.0.0-probe.1-complete-source.zip
内含 Gradle Wrapper、应用源码、测试、研究报告、完整 README 和签名构建说明；不含签名私钥或密码。
校验文件：SHA256SUMS.txt。校验值针对下载文件本身，不要解压后对另一文件使用 ZIP 校验值。
